# Интерфейс «Регулятор»

Адрес: https://dsxx1.github.io/cbr-regulatory-monitor/

Лента: поиск по заголовку, тексту и источнику; фильтры важности, источника, типа, стадии анализа; сортировка по дате или важности. Важность предварительная, не решение о применимости. Архив и контрольный пример помечены отдельно.

Карточка открывается справа. Вкладки: карточка с выводами и цитатами, текст источника, Markdown. Есть скачивание и копирование MD, переход к первоисточнику. Сохранённое хранится в localStorage текущего браузера. Общих пользовательских аккаунтов пока нет.

Раздел «Источники»: результаты последней проверки, расписание, следующий плановый запуск, границы покрытия и последнее подтверждённое состояние доставки. Состояние Б24 на 20.09.2026: блокировка imbot. Сайт не делает живых запросов к Б24.

Раздел «Качество»: вызовы, отказы, очередь, проверяющий, модели и API-квитанции. Нулевые/неизвестные значения стоимости не смешиваются.

Раздел «Модели»: черновик выбора генератора/проверяющего и лимита 1–5. Копирование или скачивание JSON → авторизованное изменение `monitor-settings.json` в GitHub. Файл реально читается облачным процессом. Форма не сохраняет секреты и не заявляет, что настройка уже применена.

SQL/Supabase не используется. Данные: cloud-state.json (текущий мониторинг), news-catalog.json (собранный архив открытых публикаций). Экспорт dashboard_export.py выдаёт только публичную проекцию public/news.json; приватные поля доставки не экспортируются. Статические исходники — web/. Каждый прогон сохраняет этот интерфейс, не заменяет старой HTML-сводкой.

Публикация UI: dashboard.yml, только public/. Обновление дизайна не запускает LLM и не отправляет сообщения в Б24.

Возможное развитие с Supabase: аутентификация, общие отметки, роли и серверное сохранение настроек. Это отдельный этап; service-role ключ в клиентский код не помещать.
