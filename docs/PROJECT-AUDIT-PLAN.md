# Аудит и план доведения проекта

Дата: 20.09.2026. Текущий контур: видимый локальный процесс, чтение по LAN, управление владельцем через localhost. GitHub Actions отключены.

## Проверки и критерии готовности

1. Интерфейс: убрать подписи «Просмотр для сотрудников» и подсказку запуска владельца; компактная широкая лента, проверка desktop/mobile и отсутствия горизонтального скролла.
2. Доступ: гостю запрещены все изменяющие API, настройки и тест моделей. Вход владельца работает только на loopback, ключ не попадает в общие данные.
3. LLM: отдельная вкладка для сообщения модели. Показать запрошенный маршрут, фактическую модель, ответ, время, токены и стоимость либо отсутствие данных. Выбранная конкретная модель не должна молча подменяться резервной.
4. Проверки моделей: цена проверяется перед запросом; только нулевая цена. Ошибки, тайм-ауты и обрезанный ответ видны. Ответ не считается доказательством юридической корректности.
5. Обработка: фактическое получение источников, очереди, повторные попытки, полнота PDF, сформированный MD. Не считать архив полностью разобранным до окончания очереди.
6. Б24: раздельно проверить право отправки ботом и право задач. Не отправлять тестовые сообщения модели в рабочий чат. Не повторять уже доставленные публикации и не создавать задачи повторно при неопределённом результате.
7. Эксплуатация: журнал ошибок без секретов, запуск/остановка, сохранение данных, резервная копия, восстановление после прерывания. Не добавлять скрытый автозапуск.

## Порядок работ

- Сначала зафиксировать состояние и дефекты, затем исправить подтверждённые ошибки.
- Реализовать и проверить вкладку моделей локальными тестами и реальным запросом.
- Пройти проверки сайта и API. Сохранить результаты в этом документе.

## Уже известные ограничения

- OCR: установлен Tesseract; Docling-адаптер пока не принят по реальному тесту. Сканы свыше 25 OCR-страниц и текст свыше лимита анализа не разбираются целиком.
- Архив ещё не обработан полностью. Бесплатные API могут отказывать и не имеют гарантии доступности.
- На последней проверке вебхуку не хватало права задач. Это отдельный барьер, не ошибка доставки ботом.
- Не проверено открытие LAN-сайта с другого физического компьютера.

Это список проверок, а не утверждение, что весь проект уже готов.

## Результат текущего аудита и исправлений

### Исправлено

- Убраны обе подписи для сотрудников/владельца. Лента занимает ширину окна; крупные счётчики скрыты, дополнительные фильтры свёрнуты.
- Добавлена закрытая вкладка «Проверка моделей»: сообщение, выбор модели, ответ, фактическое имя модели, задержка, токены, стоимость/нет данных. Тексты тестов не сохраняются и не уходят в Б24.
- Конкретная модель тестируется без скрытого fallback; автоматический маршрут показывает фактически ответившую модель.
- Архивный обработчик теперь применяет настройки выбранных моделей, а не отдельные зашитые значения.
- Завершение сбора больше не маскирует оставшиеся неотправленные сообщения.
- Добавлена проверяемая ZIP-копия SQLite и рабочих JSON без вебхука/ключа владельца; проверено восстановление в отдельный временный каталог.
- В источниках показаны сайты и ссылки. Владелец может добавить RSS 2.0 или страницу для отслеживания текста. Источники подключены к сбору, а не только к интерфейсу.
- RSS-анонс не выдаётся за полный исходник: статья загружается отдельно. Поддерживаются ссылки того же сайта; Atom, JS-рендеринг и страницы с авторизацией требуют отдельного обработчика.
- Учтён FlClash fake-IP: только для диапазона 198.18.0.0/15 используется публичное DNS-разрешение; соединение закрепляется за проверенным внешним IP с проверкой TLS имени сайта. Внутренние адреса и редиректы в них запрещены.

### Живые проверки

- Автоматические проверки: 48 тестов прошли. Включены гостевые запреты, owner-сессия, добавление источника через HTTP, применение настроек моделей к архиву и восстановление резервной копии.
- Лента и источники проверены в браузере на desktop и ширине 390 px. Горизонтального скролла страницы нет; удалённые подписи отсутствуют в видимом тексте.

- Автоматический бесплатный маршрут: ответ `42` на `17 + 25`, фактическая модель Ling, 1,8 с, 85 токенов, заявленная стоимость $0.
- Прямой Ling: `42`, 1,3 с, 85 токенов, $0.
- Прямой Poolside: HTTP 429. Интерфейс показывает лимит, платный резерв не применяется. Это не стабильность всех маршрутов и не проверка юридических выводов.
- Дополнительный RSS в изолированной тестовой конфигурации получил 13 реальных публикаций ЦБ. Тест не добавлял дублирующую ленту в рабочую конфигурацию.
- 12 источников имели статус `ok` в последнем сборе; 400 карточек, 20 готовых разборов, 5 важных. У всех карточек есть MD, но MD исходника не равен аналитическому разбору.
- Повторным чтением Б24 найдены 7 сообщений бота; очередь прикладной доставки содержит 5 отправленных материалов, без ожидающих.
- `tasks.task.getFields` по-прежнему возвращает HTTP 401 `insufficient_scope`: право задач не предоставлено.
- Гостю запрещены управляющие API, включая проверку моделей, добавление источника и резервное копирование. Настройки скрыты в JSON, не только CSS.

### Не закрыто; нельзя называть проект полностью завершённым

1. Администратор Б24 должен выдать право «Задачи»; затем нужен живой тест создания/ссылки/защиты от повторного создания.
2. 380 материалов ещё не имеют принятого разбора. Очередь должна быть обработана; остаток нельзя считать неважным.
3. Большие и сложные PDF требуют отдельного этапа: постраничные задания, разбиение текста, сводка с сохранением цитат и проверка чисел/таблиц. Docling пока не принят в рабочую цепочку.
4. Проверка открытия с другого физического компьютера и выбранная владельцем периодичность работы.

Следующий технический приоритет — большие PDF и автоматическое переосмысление старых оценок по новой политике, а не очередная косметическая правка.
