## Бесплатная модель

Сначала применён aux-llm-worker/free-auto: бесключевой маршрут Kilo, reportedCost=0. Это вспомогательный черновик, не доказательство работоспособности проекта.

В проект добавлены free_llm.py и free_llm_transport.mjs. Node встроенным fetch обращается к тому же бесплатному маршруту; локальный сервер и ключ не требуются. Перед каждым запросом проверяются все тарифные поля текущего каталога. При ненулевой или неизвестной цене запрос блокируется. Платного fallback нет; ненулевой cost в квитанции блокирует последующие вызовы.

Живая проверка на трёх разъяснениях: сначала Python transport дал сетевые ошибки, затем Node с лимитом 3000 токенов дал 2/3 пригодных ответов. После увеличения лимита до 6000 — 3/3 пригодных ответов, 17 цитат, 0 отброшенных цитат, стоимость каждого ответа по API 0. Эти три ответа сохранены, повторный вызов при пересборке не выполнялся.

Выборка мала: 3/399 материалов. Совпадение цитат проверяется программно, смысловая юридическая правильность этим не доказана. Массовый автоматический анализ всего архива пока не проверен.

Новый бот нельзя объявлять готовым: Worker не развёрнут, его API-контракт не испытан на портале; KV дедупликация не обеспечивает exactly-once при параллельных запросах или сбое между отправкой и записью KV. Нужна сверка по реальному сообщению/строгое состояние доставки перед включением. Подстановка ключа вместо подтверждённого ID сообщения также требует устранения.

Pages workflow прежнего commit требует доработки: commit с GITHUB_TOKEN не запускает новый push workflow; публикация всей docs может раскрыть внутренние инструкции. До запуска публиковать только специально подготовленную публичную папку и вызывать deploy непосредственно после мониторинга либо через workflow_run.
