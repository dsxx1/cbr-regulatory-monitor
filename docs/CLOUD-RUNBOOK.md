# Облачный запуск

Основной процесс: `.github/workflows/cloud.yml`. GitHub сам запускает Python и Node, получает открытые страницы и вызывает бесключевую бесплатную LLM. ПК сотрудника не нужен.

Расписание: будни, 09:17 и 13:17 МСК (11:17 и 15:17 Екатеринбург). Расписание GitHub может задерживаться.

Качество: первоначальная сводка LLM → точные цитаты в исходнике → отдельный вызов бесплатной Ling с ролью проверяющего → отправка. Проверяющий оценивает обязанности, субъектов, числа и сроки. Это отдельный запрос с другим заданием, не независимая юридическая экспертиза. Генератор использует free-auto; если free-auto сам выбрал Ling, модель может совпасть, несмотря на разделение заданий.

Неуспешные ответы остаются в очереди. Содержимое чата не передаётся модели. Б24-доступ выдаётся только отдельному шагу доставки. Платных fallback нет.

Публичные данные сохраняются в `cloud-state.json` и `public/`; Pages публикует только `public/`. Внутренние инструкции из `docs/` не используются для сайта.

Способы ручной проверки в Actions → «Облачный мониторинг и бот»:

- `probe`: проверить доступ к порталу и наличие методов, без сообщений.
- `control`: проверить LLM на двух настоящих архивных разъяснениях, отправить явно подписанные контрольные примеры.
- `run`: обычный мониторинг. Если нового нет, сообщения не отправляются, dashboard обновляется.

Доставка бота использует зарегистрированный `imbot.v2`, режим `fetch`, прямо из GitHub Actions. Cloudflare/Workers KV не нужны для этого процесса. `worker/` — ранний неразвёрнутый прототип, не используется.

Один workflow за раз. Неотправленное сообщение сохраняется до подтверждения доставки. Перед повтором проверяются последние 50 сообщений на совпадение ключа. Это защита от обычного повторного прогона, не математическая гарантия exactly-once после длительного простоя или удаления сообщений. После неизвестного результата отправки проверяйте чат перед повторным контрольным запуском.

Секрет `B24_WEBHOOK` должен иметь права чтения выбранного чата и доступа к ботам. Значения секретов не выводятся. Код разрешает только согласованный портал и один согласованный чат.
