# changedetection.io: проверка на Windows без Docker

20.09.2026. Проверен выпуск 0.60.7 в отдельном Python 3.12-окружении. Основное окружение РегКонтроля не изменялось.

- Через обычный resolver первый запуск был заблокирован защитой changedetection: FlClash возвращает служебные fake-IP.
- В повторном изолированном запуске для единственного домена СРО использовано публичное DNS-разрешение с проверкой внешнего IP. Глобальная опция разрешения private/reserved адресов **не включалась**.
- Получена страница `https://sro-lombard.ru/news.html`: в watch.json `last_check_status=200`, `last_error=false`, сохранены HTML и текстовый снимок, появилась запись history.txt.
- Это принятие первого снимка, не доказательство обнаружения реального изменения между двумя редакциями. Также не проверены браузерный режим, PDF и уведомления компонента.
- Batch-процесс завершён; постоянный дополнительный сервер не запущен. В действующую цепочку Б24 компонент пока не встроен, штатный сбор РегКонтроля продолжает работать.

Замечания установки: автоматический выбор на Python 3.14 установил старый пакет 0.45.14, который не запустился из-за distutils. Явно закреплён 0.60.7 на Python 3.12; зависимости требуют разрешения prerelease. Для постоянной эксплуатации нужен отдельный закреплённый набор зависимостей и приёмочный тест двух редакций.

Вывод: компонент подходит для следующего этапа обработки сложных страниц, но считать его полностью внедрённым преждевременно.
