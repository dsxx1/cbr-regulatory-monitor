# Обработка всего архива

Проблема прежней версии: в ленте был архив, но в рабочую очередь попадали только изменения после запуска. Ограничение три вызова на прогон не могло заполнить разборы архива.

Новый процесс `backfill.py` объединяет архив и текущую очередь, создаёт запись обработки на каждый материал. `analysis-queue.json` хранит попытки, время следующей попытки и причины отказов; `source-cache.json` — извлечённые публичные тексты. SQL не требуется: один облачный процесс записи, атомарное сохранение JSON после каждого документа, общий concurrency group для публикаций. Никакие SQLite/credentials в Git не добавляются.

Workflow `backfill.yml` запускается каждый час: шесть документов, два параллельных обработчика. Приоритет обработки цифрового рубля, учёта и регуляторных тем не назначает важность карточки — её определяет содержательный разбор. Между пакетами сохраняется прогресс. По таймауту сохраняется уже завершённая часть; зависшая часть остаётся на следующую попытку.

Бесплатный маршрут сверяет все цены каталога, переключается между разрешёнными free-моделями при 429, 5xx, пустом или обрезанном ответе. Платного маршрута нет. Разбор проходит схему, точные цитаты, проверку существенных числовых условий и отдельный модельный review; при замечаниях — одна попытка исправления и повторная проверка. Проверка модели не равна юридической экспертизе.

PDF с текстовым слоем извлекается через pypdf. В облачном обработчике установлены Poppler и Tesseract (русский/английский) для сканов до 25 страниц. Большие файлы и документы, требующие разбиения, помечаются явно. После пяти неудачных попыток документ требует проверки причины, а не объявляется успешно разобранным.

MD доступен для каждой карточки. Если анализ готов — это аналитический MD. Иначе — исходник с отметкой состояния обработки; если текст недоступен, в файле указаны ссылка и причина, а не вымышленный вывод. Большой текст сохраняется полностью в MD, даже если панель показывает сокращённую версию.

Главный экран показывает число готовых разборов и неоценённый остаток. «Нет важных среди готовых» не означает «в архиве нет важных новостей».

Облачный процесс не зависит от рабочего ПК и не отправляет старые архивные материалы в чат. Текущие сообщения Б24 остаются в отдельном workflow; право imbot по-прежнему требуется для бота.
