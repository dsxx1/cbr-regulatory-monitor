# Запуск без Docker

Двойной щелчок по `ЗАПУСТИТЬ.cmd`. Откроется отдельное видимое окно.
Сайт: http://localhost:8787 . Этапы и ошибки видны в окне и на сайте.

- «Проверить новости» запускает реальную проверку.
- «Расписание» включает/выключает проверки раз в час. Выключение расписания не прерывает текущую проверку.
- «Остановить процесс» или Ctrl+C завершает сервер и активные дочерние задания.
- Для повторного запуска снова откройте `ЗАПУСТИТЬ.cmd`.

Автозапуска нет. После выключения ПК мониторинг не работает. GitHub Actions отключены; Docker-контейнер остановлен.
Данные сохраняются в `runtime/local-data`: SQLite — задания и доставка, JSON/Markdown — материалы.
Вебхук находится в исключённом из Git `secrets.txt`. Не публикуйте этот файл.
Архив при первом запуске не рассылается. Новые материалы отправляются в согласованный чат ботом.

Для OCR установлены Tesseract 5.5.3 с русским/английским языками в `C:\projects\cbr-regulatory-monitor-tools\tesseract` и имеющийся Poppler. Пути добавляются только в окружение запуска.
OCR проверен на первой странице реального скана ЦБ: текст получен, но точность реквизитов не гарантируется; их нужно сверять с PDF. Автоматический лимит — 25 страниц, требующих OCR; большие документы остаются в очереди без обрезания.
Docling подготовлен как отдельный адаптер, но его качество и производительность на этой машине ещё не подтверждены.
