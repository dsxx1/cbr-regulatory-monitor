# Запуск без Docker

Двойной щелчок по `ЗАПУСТИТЬ.cmd`. Откроется отдельное видимое окно.
Для коллег: http://10.10.138.203:8787 . Для владельца: http://localhost:8787 . Этапы и ошибки видны в окне и в режиме владельца.

## Доступ

- Сотрудники в локальной сети видят новости, поиск, источники и Markdown. Управляющие команды и настройки закрыты сервером.
- Владелец открывает `ВХОД-ВЛАДЕЛЬЦА.cmd` на этом ПК: создаётся сессия на 8 часов. Ключ не нужно копировать в чат или вводить вручную.
- Вход владельца разрешён только через localhost. Ключ `runtime/local-data/owner.key` доступен по NTFS только текущему пользователю Windows и SYSTEM, не входит в Git.
- После перезапуска сервера нужно снова открыть вход владельца. Обычный вход по localhost без сессии тоже даёт только просмотр.
- «Проверка моделей» — отдельный тестовый чат владельца. Конкретная модель не подменяется резервной; автоматический маршрут показывает фактическую модель. Запрос не сохраняется и не отправляется в Б24.
- «Источники» — ссылки на сайты и результаты проверки. «Добавить источник» доступно владельцу: RSS 2.0 того же сайта либо отслеживание изменений HTML-страницы. Новый источник включается в следующий сбор. Atom, авторизация и JavaScript-рендеринг автоматически не поддерживаются.
- «Управление → Резервная копия» сохраняет проверенный ZIP в `runtime/backups`. Копия не содержит вебхук и ключ владельца; для согласованности дождитесь окончания текущей проверки.
- Windows Firewall: TCP 8787, LocalSubnet, Domain/Private. Нет проброса порта через интернет. Доступ с другого компьютера ещё требует проверки пользователем; на этом ПК сетевой адрес отвечает.
- IP может измениться при смене сети/DHCP. Постоянный адрес или DNS-имя согласуется с ИТ.

- «Проверить новости» запускает реальную проверку.
- «Расписание» включает/выключает проверки раз в час. Выключение расписания не прерывает текущую проверку.
- «Остановить процесс» или Ctrl+C завершает сервер и активные дочерние задания.
- Для повторного запуска снова откройте `ЗАПУСТИТЬ.cmd`.

Автозапуска нет. После выключения ПК мониторинг не работает. GitHub Actions отключены; Docker-контейнер остановлен.
Данные сохраняются в `runtime/local-data`: SQLite — задания и доставка, JSON/Markdown — материалы.
Вебхук находится в исключённом из Git `secrets.txt`. Не публикуйте этот файл.
Архив при первом запуске не рассылается. Новые материалы отправляются в согласованный чат ботом.

Для OCR установлены Tesseract 5.5.3 с русским/английским языками в `C:\projects\cbr-regulatory-monitor-tools\tesseract` и имеющийся Poppler. Пути добавляются только в окружение запуска.
OCR проверен на первой странице реального скана ЦБ: текст получен, но точность реквизитов не гарантируется; их нужно сверять с PDF. Автоматический лимит — 25 страниц, требующих OCR; большие документы остаются в очереди без обрезания.
Docling подготовлен как отдельный адаптер, но его качество и производительность на этой машине ещё не подтверждены.
