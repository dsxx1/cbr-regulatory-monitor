C 22.08.2026 планируется перевод Личного кабинета на использование SSL-сертификатов Национального удостоверяющего центра (НУЦ) Минцифры России.
Для обеспечения бесперебойного взаимодействия с Личным кабинетом через веб-интерфейс рекомендуется использовать «Яндекс браузер», поддерживающий российские сертификаты безопасности.
При использовании иных браузеров, в случае возникновения проблем (ошибок) при взаимодействии с Личным кабинетом, необходимо установить сертификаты НУЦ Минцифры России.
Подробная инструкция по установке сертификатов для ОС «Windows», «MacOS», «Linux», а также по настройке REST-API сервиса и программного продукта «Дельта», размещена в разделе «Информационные ресурсы / Инструкции по работе с ЛК»Личного кабинета.
