# Пользователи личного кабинета Росфинмониторинга начали массово сталкиваться со сбоями при попытке войти на портал ведомства

Это исходный материал, а не подтверждённый аналитический разбор.

Пользователи личного кабинета Росфинмониторинга начали массово сталкиваться со сбоями при попытке войти на портал ведомства (portal.fedsfm.ru).
Причиной тому стала блокировка сертификата сайта со стороны компании GlobalSign, которая выдаёт сертификаты для сайтов по всему миру. При наличии такого сертификата браузеры считают, что сайт безопасный и его можно открывать. Причиной отзыва сертификата Росфинмониторинга стала санкционная политика.
В настоящее время проводятся работы по выпуску сертификата Минцифры России.
Как быть?
Для работы с порталом рекомендуется использовать ссылку: https://portal.fedsfm.ru:8081/
(использовать браузеры Яндекс, Хромиум-Гост, Edge)
При наличии сертификата ключа (электронной цифровой подписи) по указанной ссылке сайт доступен.
